# AI-переводчик карточек товаров (Product Card Translator)

Консольная утилита на Python для автоматизированного чернового перевода каталогов товаров (названий и описаний) из формата CSV с использованием языковых моделей (LLM) через API Ollama.

## Возможности проекта
- Пакетная обработка CSV-файлов с сохранением исходных столбцов и добавлением колонок перевода (`title_<lang>`, `description_<lang>`).
- Автоматическая фильтрация пустых и некорректных строк при помощи библиотеки `pandas`.
- Строгий JSON-формат ответа от нейросети для точного разделения названия и описания товара.
- Отказоустойчивость: автоматические повторные попытки (`retry` до 3 раз) при сетевых сбоях и таймаутах, а также настраиваемая пауза между запросами (`--delay`).
- Подробное логирование всех этапов работы в консоль и файл `app.log` с замером времени выполнения функций.

## Структура проекта
```text
project/
├── main.py            # Точка входа, CLI-интерфейс (argparse) и основной цикл обработки
├── ai_client.py       # Клиент для взаимодействия с Ollama API, промптинг и логика retry
├── data_utils.py      # Загрузка, фильтрация пустых записей и сохранение CSV (pandas)
├── logger.py          # Настройка логирования и декоратор @log_execution
├── requirements.txt   # Список зависимостей проекта
├── .env.example       # Шаблон файла конфигурации с переменными окружения
├── input.csv          # Пример входного файла с карточками товаров
└── README.md          # Документация проекта
```

## Установка и настройка

1. **Клонируйте репозиторий или скачайте файлы проекта** и перейдите в рабочую директорию:
   ```bash
   cd project
   ```

2. **Установите зависимости:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Настройте окружение:**
   Создайте файл `.env` на основе `.env.example`:
   ```bash
   cp .env.example .env
   ```
   Укажите параметры подключения к локальному или облачному серверу Ollama:
   ```env
   OLLAMA_API_KEY=ollama
   OLLAMA_BASE_URL=http://localhost:11434/v1
   OLLAMA_MODEL=qwen2.5:3b
   ```

## Примеры запуска

Базовый запуск с параметрами по умолчанию (перевод `input.csv` на английский язык в `output.csv`):
```bash
python main.py
```

Запуск с указанием собственных файлов, целевого языка и задержки между запросами:
```bash
python main.py --input catalog_ru.csv --output catalog_en.csv --lang English --delay 0.5
```

Перевод карточек на другой язык (например, немецкий или китайский):
```bash
python main.py -i input.csv -o output_de.csv -l German
```

## Обработка ошибок и краевых случаев
- **Пустой входной файл:** если CSV не содержит строк или все карточки пустые, программа выводит сообщение `Нет данных` и корректно завершает работу без обращения к API.
- **Неверный API-ключ или ошибка авторизации:** перехватывается исключение `AuthenticationError`, пользователю выводится понятная подсказка проверить `.env`.
- **Сбои сети и превышение лимитов (Rate Limit):** декоратор `@retry` выполняет до 3 повторных попыток с экспоненциальной задержкой. Если карточка не переведена после всех попыток, она помечается как `[ОШИБКА ПЕРЕВОДА]`, а обработка остального каталога продолжается.
